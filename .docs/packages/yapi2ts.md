# Yapi2ts 接口拉取工具

在我们系统中，接口都是通过脚本来自动更新的，这里会调用 yapi 的 openAPI 接口，拿到接口的一些元数据，然后生成对应的 ts 类型文件。

## 如何使用

假定我们已经安装好依赖后

1. `cd apps/public/apis`
2. `pnpm api`
3. 此时会在当前目录下的 services 中，生成出对应的文件

具体可以查看[apis](../apps/public/apis.md)的使用方式

## 常见问题

1. 拉取接口报错
   - 通常发生在项目刚刚新建的时候，后端此时还未上传好 yapi
2. 项目运行时报错缺少接口

- 需要联系后端同事将对应的接口补充上传到 yapi，前端再重新拉取即可
