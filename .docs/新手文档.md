# 环境准备

1. 安装[vscode](https://code.visualstudio.com/)，vscode 是前端开发最常用的 ide，推荐使用最新版本即可

2. 安装[nodejs](https://nodejs.org/en)，nodejs 是前端开发最常用的运行环境，我们项目使用的版本为**20.18.3**，在安装完 nodejs 后，会自带同步安装 `npm`，`npm` 是前端用来管理依赖包的工具（类似 java 中的 maven），每个 nodejs 版本都会对应一个 npm 版本。

> 更多的时候，我们会使用 `nvm` 来管理 nodejs 版本，`nvm` 是一个 nodejs 版本管理工具，它可以帮助我们在一台机器上安装多个 nodejs 版本，并且切换版本。[下载地址](https://nvm.uihtm.com/doc/download-nvm.html)

3. 安装[pnpm](https://pnpm.io/zh/installation)，pnpm 相当于是 npm 的加强版，我们的项目所有的依赖管理都是通过 pnpm 来操作的。

> `npm i -g pnpm@10.4.1` 这样就可以全局安装 `pnpm` > `pnpm -v` 看看能否输出对应的版本号

4. 在根目录下，运行 `pnpm install`，这将会给整个前端项目安装好所有依赖

5. `cd apps/public/api` 运行 `pnpm api`

   > 这将会从 yapi 上读取接口并拉到本地

6. `cd apps/project/admin` 运行 `pnpm dev` 此时应该能看到启动成功，并且有 `localhost:4399`的链接输出

如果要运行能力中心 则是 cd 到 platform 中，各个目录的启动命令基本都是一样的

7. 如果需要更换本地启动的网关地址，则需要修改 `apps/public/config/index.js` 中的 `DEFAULT_ENV_TYPE` 变量，代表的是当前运行的环境，默认是 test 测试环境

其中 dev -> dev test -> site uat -> uat prod -> prod

同级目录下有对应的环境变量文件

`BACK_GATEWAY` 就是网关地址，其中 `process.env.BACK_GATEWAY` 代表 jenkins 上注入的环境变量，而本地我们会使用后者，所以本地要运行不同的网关地址时，则只需要更换后者的默认值即可
