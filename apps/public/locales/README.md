# @apps/locales

## 使用前，请先在插件市场中安装 i18n-ally, 你将获得非常良好的开发体验

例如

1. 代码中会显示对应中文

2. 选中页面的文案后，点击左侧黄色灯泡，可自动填充对应的 key，或者直接补充

3. 对未翻译的文案，可直接在页面中一键翻译

4. 更多可详细体验

## 具体结构

- 国际化
  - web(pc 端)
    - 语言包（zh-CN,ko-KR,en-US 等）
    - common(公共内容)
      - resource(页面上具体国际化文本)
      - extra(二开项目新增或修改)
  - mobile(移动端)
    - 语言包（zh-CN,ko-KR,en-US 等）
    - common(公共内容)
      - resource(页面上具体国际化文本)
      - extra(二开项目新增或修改)

## 归类方式

- 按照语言的类型进行分类
  > 方便进行整包移除或复制，但是开发时不能聚焦单个模块

## 国际化 key 值的格式

- 统一用`.`进行分割

- key 的前缀用对应划分的类型名称作为前缀
  - > 例如: common.xxxx

---

    :::note
    	如果文本长度过长的话建议使用场景名称作为key值(个人建议)
    :::

- key 在各端中必须是唯一值
